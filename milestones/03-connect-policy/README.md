# M3 接続拒否と解除

状態：未着手。前提：M2。

## 到達点

事前ルールで対象 cgroup の TCP 新規接続を拒否できる。

## 実装先の予定

ebpf/policy.rs、user/{cli.rs,policy.rs}、tests/vm/cases。詳細は [ディレクトリ構成](../../docs/DIRECTORY_LAYOUT.md) を参照。

## 作業

- [ ] family・IP・port・protocol の tuple でルールを作る。
- [ ] observe を既定にし、enforce でのみ Map に従い拒否する。
- [ ] 一つのルールの追加/解除と、更新成功・失敗・現状の表示を実装する。
- [ ] 両 family の準備完了前にテストクライアントを起動しない。

## 合格条件

- [ ] 拒否ルールを接続前に登録し、IPv4/IPv6 の新規接続が拒否され、サーバーに届かない。
- [ ] ルール解除で新規接続が成功する。未登録 port と対象外クライアントは影響を受けない。
- [ ] 既存接続は停止しないことを確認し、制約として表示する。
- [ ] Map 容量不足/更新失敗は成功扱いにならない。
- [ ] 一方の attach 失敗、通常終了、SIGTERM、SIGKILL 後にリンクが残らず接続が復帰する。
- [ ] クライアント errno、サーバー受信、SSH 維持を記録する。

## 中止と対象外

対象外への影響や解除失敗があれば遮断機能を完成扱いにしない。プロセス kill と firewall バイパスは追加しない。
